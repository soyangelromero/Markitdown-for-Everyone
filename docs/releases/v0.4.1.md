# v0.4.1

A maintenance release: clearer API errors, a green CI matrix and a landing-page refresh.

## Highlights

- **Specific API errors:** invalid keys (401), insufficient pollen (402), missing model
  permissions (403) and rate limits (429) are shown again when MarkItDown wraps the original
  exception in `FileConversionException` (`attempts[].exc_info` is inspected).
- **CI fixed and green** on Ubuntu, Windows and macOS with Python 3.10 and 3.13, plus lint and
  type checks. A test no longer monkeypatches `os.name` (which broke `pathlib` on POSIX).
- **Verified from a clean clone** against the live Pollinations API: config flow, key handling,
  TXT/DOCX/PDF conversion, image vision, scanned-PDF OCR, invalid-key errors and exit codes.
- **README refresh:** demo GIF (`docs/demo.gif`), "Why this tool?" comparison table, one-line
  install with `uvx`/`pipx`, and a Spanish version.
- **Release tooling:** `docs/PUBLISHING.md` and a manual PyPI Trusted Publishing workflow
  (`.github/workflows/publish.yml`).
- **Launch kit:** ready-to-edit drafts for Show HN, Reddit (EN/ES), LinkedIn, X and awesome
  lists in `docs/launch/`.

## Install

PyPI publication is pending. Until then:

```bash
uvx --from git+https://github.com/soyangelromero/Markitdown-for-Everyone.git markitdown-for-everyone
# or
pipx install git+https://github.com/soyangelromero/Markitdown-for-Everyone.git
```

Or download `markitdown_for_everyone-0.4.1-py3-none-any.whl` from this release and run
`pipx install ./markitdown_for_everyone-0.4.1-py3-none-any.whl`.

## Requirements

- Python 3.10+
- A free Pollinations key from <https://enter.pollinations.ai> for images/OCR
  (`POLLINATIONS_API_KEY` or the interactive setup)
